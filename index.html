Connect image search

One-time setup. Create a free Google Programmable Search Engine, then paste its Search engine ID below.

  1. Open Google Programmable Search and create an engine.
  2. Under Sites to search, add aliexpress.com.
  3. Turn Image search on. Under Look and Feel → Layout, select Results only, then Save (not Overlay).
  4. In the engine's Overview → Basic section, copy the Search engine ID.

This ID is stored only in this browser. No Google Cloud API key is needed. The standard Google Search Element may display ads.
